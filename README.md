# 1% Lebih Baik Setiap Hari — Motion Graphic TikTok

Video motivasi hidup & keuangan, gaya hitam-putih, 1080×1920 (9:16), 30 fps, 40 detik.
Akun: **SUARA (@.notingme)**

## Alur
| Waktu | Adegan |
|---|---|
| 0–5 dtk | Hook: 1,01³⁶⁵ = 37,78 vs 0,99³⁶⁵ = 0,03 |
| 5–9,6 | "Bedanya cuma 1% sehari." → menyusut jadi satu titik |
| 9,6–16 | HIDUP: titik tumbuh jadi jaringan (baca, jalan, belajar) |
| 16–25 | UANG: Rp10.000/hari → grafik majemuk ±Rp49,2 juta (10 th, asumsi 6%/th) |
| 25–32 | Pohon tumbuh: "Awalnya tak terlihat… sampai suatu hari semua orang melihatnya." |
| 32–40 | "Mulai hari ini. Bukan besok." + Follow & Share @.notingme |

## Cara pakai
- Preview: buka `index.html` di browser.
- Render MP4: `node render.js` → `output/1-persen-lebih-baik.mp4` (butuh Playwright + ffmpeg).
- Ganti akun: `node render.js --handle @akunlain --brand NAMA`.
- Teks, angka tabungan, dan asumsi imbal hasil ada di `CONFIG` & fungsi scene di `index.html`.

Video tanpa musik (audio hening) — tambahkan sound trending langsung di TikTok.
